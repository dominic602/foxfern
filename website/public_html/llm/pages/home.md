## How does a project work?

1. **On-site walkthrough.** The team walks the space, takes measurements and talks through what you want.
2. **Itemized estimate.** A clear, itemized estimate with a fixed price and written payment terms. It only changes if you sign a change order.
3. **Design and samples, if needed.** Renderings, material sourcing and samples, so you can see it before it is built.
4. **A dedicated project manager.** Once you approve, a dedicated project manager takes over: clear communication and daily quality control.
5. **Build, with daily updates.** Your online project folder is updated every working day with what was done, photos and what's next.
6. **Final walkthrough and closeout.** Every touch-up is completed; you receive warranty certificates and a product sheet listing the exact products used.
